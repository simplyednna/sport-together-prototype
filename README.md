# Sport Together – UI/UX Prototype

This repository contains the UI/UX prototype for **Sport Together**, developed as part of the Advanced Software Engineering project at TU Wien.

The prototype was originally created using Figma Make and serves as a design reference for the development team.

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS

## Getting Started

### Prerequisites

- Node.js 22
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/simplyednna/sport-together-prototype.git
   ```

2. Navigate into the project directory:

   ```bash
   cd sport-together-prototype
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Project Structure

- `src/App.tsx` – Main application component
- `src/data.ts` – Sample data used in the prototype
- `src/index.css` – Global styles
- `public/` – Static assets

## Important Note

This repository contains a **UI/UX prototype**, not the production application.

The actual Sport Together application is developed separately using Vue.js and Spring Boot.

The prototype serves as a visual and functional reference for implementing the final user interface.
